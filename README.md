## 🚀 Projetos em destaque

> Os projetos abaixo foram descritos com base no currículo enviado. Confira e associe cada título ao repositório correto antes de publicar.

### 🔹 Projeto Full Stack — Node.js, Express e PostgreSQL
Aplicação com API REST, integração entre front-end e back-end, operações CRUD e persistência de dados.

**Destaques:** autenticação, gerenciamento de usuários e produtos, envio de e-mails com Nodemailer e migrations com Knex.js.

**Tecnologias:** JavaScript, Node.js, Express, Knex.js, PostgreSQL.

### 📊 Análise Preditiva do Mercado Imobiliário da Paraíba
Projeto de Ciência de Dados baseado em **4.944 anúncios da OLX**, com preparação de dados, modelagem preditiva, clusterização e análise de anomalias.

**Técnicas e ferramentas:** Python, Pandas, Scikit-learn, Matplotlib, Seaborn e NLP.

### 🧠 Análise de Sentimentos com Deep Learning
Projeto de classificação de sentimentos a partir de imagens, envolvendo pré-processamento, aumento de dados, treinamento e avaliação de uma rede neural convolucional (CNN).

**Tecnologias:** Python, TensorFlow, Keras e OpenCV.

### ⚽ LCI Sports — Gestão de Partidas e Arenas
Sistema proposto para organizar partidas amadoras e administrar arenas esportivas, com funcionalidades de reservas, agenda, pagamentos e controle de acesso.

**Tecnologias:** JavaScript, Node.js, Express, PostgreSQL, HTML e CSS.

### 🏢 Plataforma de Gestão de Condomínios
Proposta de solução para centralizar informações de moradores e unidades, boletos, reservas de áreas comuns, comunicados e relatórios administrativos.

### 🔁 Conversor de Unidades de Comprimento
Aplicação web para converter valores entre diferentes unidades de comprimento, com interface simples e objetiva.

**Tecnologias:** HTML5, CSS3 e JavaScript.
