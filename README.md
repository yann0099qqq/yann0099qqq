## `01` — Sobre mim

Sou graduado em **Análise e Desenvolvimento de Sistemas pela Universidade Estadual da Paraíba (UEPB)** e tenho interesse em desenvolver aplicações web, APIs, soluções com dados e sistemas que resolvam problemas reais.

Minha experiência acadêmica envolve integração entre front-end e back-end, operações CRUD, bancos de dados relacionais e projetos de análise preditiva. Gosto de aprender na prática, organizar soluções e evoluir a cada projeto.

- **Foco atual:** desenvolvimento de software e aplicações Full-Stack
- **Também exploro:** Ciência de Dados, Machine Learning e IA
- **Base técnica:** JavaScript, Node.js, Express, PostgreSQL e Python
- **Objetivo:** contribuir com projetos relevantes e continuar crescendo na área de tecnologia

### ◈ Full-Stack — API REST e banco de dados
Aplicação acadêmica com integração entre front-end e back-end, operações CRUD e persistência de dados. O currículo destaca autenticação, gestão de usuários e produtos, envio de e-mails com Nodemailer e migrations com Knex.js.

`Node.js` `Express` `Knex.js` `PostgreSQL`

### ◈ Análise Preditiva do Mercado Imobiliário da Paraíba
Projeto de Ciência de Dados baseado em **4.944 anúncios da OLX**, com preparação de dados, modelos preditivos, clusterização e investigação de anomalias.

`Python` `Pandas` `Scikit-learn` `Matplotlib` `Seaborn` `NLP`

[Ver repositório de análise de dados](https://github.com/GabrielDnz1/An-lise-de-dados---OLX-Para-ba)

### ◈ Análise de Sentimentos com Deep Learning
Projeto acadêmico de classificação de sentimentos a partir de imagens, com pré-processamento, aumento de dados e treinamento e avaliação de uma rede neural convolucional (CNN).

`Python` `TensorFlow` `Keras` `OpenCV`

### ◈ LCI Sports — Gestão de Partidas e Arenas
Proposta de sistema para organizar partidas amadoras e administrar arenas esportivas, com reservas, agenda, pagamentos e controle de acesso.

`JavaScript` `Node.js` `Express` `PostgreSQL` `HTML` `CSS`

### ◈ Plataforma de Gestão de Condomínios
Conceito de solução para centralizar moradores, unidades, boletos, reservas de áreas comuns, comunicados e relatórios administrativos.

### ◈ Conversor de Unidades de Comprimento
Aplicação web para converter valores entre diferentes unidades de comprimento, com interface direta e foco na usabilidade.

`HTML5` `CSS3` `JavaScript`
